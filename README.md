# The Hate Thermometer

**Miscalibrated Judges: A Psychometric Evaluation of LLMs as Hate Speech Raters**  
*Accepted at AIES 2026 — AAAI/ACM AI, Ethics and Society*

---

## Overview

This is the project website for **The Hate Thermometer** — the first psychometric evaluation of LLMs as hate speech 
annotators using the Many-Facet Rasch Model (MFRM).

We evaluate 5 frontier LLMs (GPT-5, GPT-5-mini, Claude, 
Gemini, DeepSeek) against 582 human raters across 10 hate 
speech dimensions on the Measuring Hate Speech corpus.
